# Changelog

All notable changes to Token Todo are documented here.

## [0.2.0] - 2026-09-02

- Reframed the skill around a resource-and-work contract with a current-value target, trusted baseline, protected state, acceptance checks, non-goals, and explicit effects.
- Added current-reason and counterfactual rules so expiring capacity cannot become the sole justification for work or residue.
- Added root-first correction guidance for selected tasks whose architecture, data model, interface, or core assumption proves wrong.
- Added a dependency-free repository validator, bilingual structural checks, machine-readable behavioral scenarios, CI, design notes, repository guidance, and issue/PR templates.
- Reworked both READMEs to document installation, routing boundaries, scheduling defaults, safety lifecycle, validation, and design provenance.

## [0.1.0] - 2026-09-02

- Initial public skill-only plugin.
- Added explicit-only invocation and user-provided resource envelopes.
- Added conservative scheduling modes, abstract range estimates, project-local ledger guidance, approval gates, checkpoints, interruption rules, and rollback protocol.
- Added bilingual README files, Goal/prompt templates, trigger forward-tests, and MIT licensing.
